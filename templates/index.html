GET /api/check/<id>

Verificar si un ID existe

curl http://localhost:5000/api/check/ID123
GET /api/state/<id>

Obtener estado actual de un ID

curl http://localhost:5000/api/state/ID123
PUT /api/state/<id>

Actualizar estado de un ID

curl -X PUT -H "Content-Type: application/json" -d '{"state":"activo"}' http://localhost:5000/api/state/ID123
DELETE /api/delete/<id>

Eliminar un ID

curl -X DELETE http://localhost:5000/api/delete/ID123
